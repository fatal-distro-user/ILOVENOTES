# ILOVENOTES documentation

ILOVENOTES is a local-first app for notes, an infinite canvas, PDF annotation, painting and flipbook animation. Everything is stored on your device. See the [project README](../README.md) for the feature matrix and the full keyboard shortcut tables.

## Conventions used in these pages

- `Mod` means Ctrl on Windows and Linux, and Cmd on macOS.
- "Command palette" means the `Mod+K` palette. Many actions that have no shortcut are reachable there by name.
- Shortcut tables live in the [project README](../README.md#keyboard-shortcuts) and are not repeated here.
